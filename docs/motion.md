# 動きの約束（モーション仕様）

CVerse の動きは「何十ものノードを続けて押して渡り歩く」使い方のためにある。
良し悪しは 1 回目ではなく **20 回目の切り替え** で決まる。気持ちよくても、20 回目に待たされたら失敗。

この仕様は、3 つの草案（全体の決まり・相関図・画面部品）を並行して書き、
2 つの批評（見た目と体験・性能と実装）で削って決めた。値の正は `web/src/lib/motion.ts`、CSS の同じ名前の変数は
`web/src/styles.css` の `:root` にあり、`motion.test.ts` が一致を確かめる。

## 性格: すぐ・正確・静か・つながり

| 性格 | 意味 | だから |
|---|---|---|
| すぐ | 押した瞬間に動き出す | 出だしの速い曲線（最初の 1/4 で 6 割進む）。待ってから動くものは作らない |
| 正確 | 何がどこへ行ったか追える | 前からいたものは今の位置から動く。消えるものは薄れるだけで、飛ばない |
| 静か | 動きが情報を邪魔しない | 弾み（行き過ぎ）は強調 1 か所だけ。繰り返し動き続けるものは作らない |
| つながり | 相関図であることを動きで見せる | 見せ場は 1 つ「縁が蝶番になる」（下記） |

## 値（トークン）

| 名前 | 値 | 使うところ |
|---|---|---|
| `--dur-instant` | 90ms | 押した感触、色の変化 |
| `--dur-fast` | 150ms | ポップオーバー、名札の出現、動きを減らす設定のフェード |
| `--dur-base` | 240ms | パネルの中身、シート、拡大縮小、連打したときの中心の切り替え |
| `--dur-slow` | 360ms | 大きな面（Phase 2 のタイムアタックの 1 手など） |
| `--dur-scene` | 480ms | 中心の切り替え（段差込みの上限） |
| `--ease-enter` | `cubic-bezier(0.16, 1, 0.3, 1)` | 現れる |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 去る（入るの 0.7 倍の長さ） |
| `--ease-move` | `cubic-bezier(0.2, 0, 0, 1)` | 居続けて場所を移る（図のノード、カメラ、シート） |
| `--ease-emphasis` | `cubic-bezier(0.34, 1.36, 0.64, 1)` | 強調。行き過ぎ約 4%。**1 画面に 1 つまで** |
| `--dist-nudge` / `--dist-s` / `--dist-m` | 4 / 8 / 16px | 入るときにずらす距離 |
| `--scale-from` | 0.96 | ポップオーバーの出始めの大きさ |

- 長さの段は、隣どうしの比を 1.3 以上にする（違いが目で分かるように）
- `ease`・`ease-in-out`・`linear`（色以外）・`transition: all` は使わない。`transition` と `animation` の長さは必ずトークンで書く
- 位置を移すのに `top` / `left` / `width` を動かさない（`transform` / `translate` / `opacity` だけ）。シートの `height` だけは Phase 2 まで例外

## 見せ場: 縁が蝶番になる

中心を切り替えるとき、**前の中心と新しい中心をつなぐ線（いまたどった縁）を、動いているあいだだけ牡丹にする**。
図はこの線を蝶番にして回り込み、着地して 150ms たつと線は普通の色に戻る。

- 「どの縁をたどってここへ来たか」が毎回 1 本の線で見える。人物相関図というコンセプトを、動きそのものにしたもの
- 牡丹は「選択・経路」にだけ使う約束に合う（たどった縁は小さな経路）
- 検索などで、つながっていない人へ飛んだときは線が無いので、何もしない
- **動きを減らす設定でも残す。** 色の変化は前庭への負担にならず、位置が動かなくても「どこから来たか」が伝わる

## 中心の切り替え（相関図）

起きる順: 押す → 場面が届く → 図が動く（480ms 以内）／パネルの中身が替わる（遅れ 90ms、240ms）。

| 対象 | 動き |
|---|---|
| 前からいるノード | 今の位置から行き先へ。`move`、480ms |
| 新しいノード | 親（無ければ前の中心）の位置から出る。`enter`。大きさは面積で育つ（`size = to × √(0.16 + 0.84k)`） |
| 出る順 | 同じ段の中は 12 時から時計回りに 0〜60ms、段ごとに +60ms。遅れの上限 120ms、各ノードの長さ = 480 − 自分の遅れ。400 ノードを超えたら段差なし |
| 消えるノード | 透明度だけ 168ms（240 × 0.7）、`exit`。寄せたり縮めたりしない。薄れているあいだは押せない |
| 線 | 線ごとに残し、不透明度は両端のノードの小さい方に合わせる（線だけ先に出たり、宙に残ったりしない） |
| カメラと図の範囲 | ノードと同じ曲線・同じ時計（`requestAnimationFrame` の 1 本）で動かす |
| 名札 | 動いているあいだは必ず出す名札（中心・指しているノード・経路）だけ。止まったら重なりを 1 回だけ判定して、残りを 150ms で出す |
| 絵 | 動いているあいだは行き先の大きさで細かさを決める（途中で頼み直さない） |

### 割り込みの規則

- 動いている途中で次の場面が来たら、**今見えている値から** 次へ動く（飛ばない、戻らない、溜めない）
- 前の切り替えが始まってから 480ms 以内に次が来たら、次は 240ms で動く（続けて押す人を待たせない）
- 途中で消えかけのノードが次の場面にもいなければ、すぐ落とす
- タブが隠れたら終わりの状態へ飛ばす
- 不透明度が 0.5 未満のノード（出始め・消えかけ）は押しても反応しない（親の位置に重なって見えない子を押させない）

## 画面部品

| 部品 | 動き |
|---|---|
| 詳細パネルの中身 | 中心が替わるたび、透明度 + 上へ 4px、`enter`、240ms、遅れ 90ms。横には滑らせない。一覧の行に段差は付けない |
| 詳細の読み込み | 手元にあるデータは同じフレームで描く（骨組みを一瞬も出さない）。無いときだけ、150ms 待ってから骨組みを出す。骨組みに流れる帯は付けない |
| 先に読み始める | 一覧の行を押し始めたとき・フォーカスしたときに、その詳細のデータを取りに行く（なぞっただけでは読まない） |
| ポップオーバー・検索候補 | 開くとき 150ms、`enter`、0.96 から（`@starting-style`）。閉じるのは即時 |
| ボタン | 押したとき 0.97 に縮む（90ms）。色は 90ms |
| シート（スマホ） | 開閉 240ms、`move`、弾みなし |
| 拡大・縮小・全体表示 | 240ms、`move` |
| スクロール | 年表の年へ移るときなどの滑らかなスクロールは、動きを減らす設定では即時 |

## 動きを減らす設定

- 位置・大きさ・カメラは動かさない（即時）。代わりに図全体を 150ms の透明度で切り替える（0.4 → 1）
- CSS では距離が 0、`--scale-from` が 1、`--dur-slow` と `--dur-scene` が 150ms になる。透明度の変化は残る
- 蝶番の線の色は残す
- 設定を途中で変えたら、次の切り替えから効く

## やらないこと

- 動きのためにフォーカスの移動や読み上げ（`aria-live`）を遅らせない。確定した時点で行う
- 繰り返し動き続けるもの（点滅、流れる帯、探索中の点）
- 一斉に弾むもの。ノードの出現の弾み、指したときの拡大
- 横揺れ（進めないことを伝えるのは文で）
- 数字の数え上げ、紙吹雪、画面全体の切り抜き、配色を円で広げる
- 写真が飛ぶ遷移（View Transitions）を中心の切り替えで使うこと。遷移中は押す操作を吸い、続けて押す使い方とぶつかる

## Phase 2（後で。上から順に）

1. 指したときのつながりの強調。詳細パネルの行に指・フォーカスを当てたときも、図の同じノードに輪を出す（キーボードでも効く）
2. 経路を 1 本ずつ引く（800ms 上限、`move`）。重ね描きのキャンバスで引き、一覧にも同じ拍で印を付ける
3. 絵が届いたら頭文字から 150ms でクロスフェード
4. タイムアタック: 開始の波紋、ゴールで牡丹が開く（8 枚、自己ベストで 12 枚）。結果の札は出すだけ
5. シートを `translate` に作り替え、指に追従させる（ばね）
6. 入口 → 相関図（パネルが入るだけ。写真を飛ばすのを試すならここ 1 か所）
7. 選択中の札が滑る、年へ移ったときの下線、星の弾み（`emphasis`）、入れ替えボタンの回転、使い方の窓
8. 重い端末の自動判定、Playwright で途中のコマと長いフレームを数える

## 確かめ方

- `motion.test.ts`: CSS と TS の値の一致、段の比、曲線の形（`move` の f(0.25) ≥ 0.55 など）、`styles.css` に生の長さや `ease` が無いこと
- `sceneMotion.test.ts`: 割り込みで飛ばない、段差込みで 480ms 以内、連打で 240ms 以内、動きを減らす設定で位置が即時、時計回りの遅れ
- 実画面: 性能は本番ビルド（`npm run build` → `npm run preview`）で、変える前と後を比べる。開発サーバーの数字は使わない
- 手で: 20 ノードを 1 秒に 2 回の速さで続けて押しても、押し損じ・溜まり・名札のちらつきが無い。動きを減らす設定で位置が動かない
